# Agent Craft

Maintain the repository's agent environment, instructions, and skills. Choose the branch that matches the request:

- **Audit repository agent-readiness** ("is this repo agent-ready?", "why do agents struggle here?"): read and follow [Agent Readiness](references/agent-readiness.md).
- **Author or edit skills, `AGENTS.md`, or `CLAUDE.md`**: read and follow [Writing for Agents](references/writing-for-agents.md) (and [Skill Mechanics](SKILL-MECHANICS.md) for frontmatter, invocation choice, and router skills).
- **Mine past sessions for recurring corrections** ("learn from my sessions", "what do I keep correcting?"): read and follow [Learn from Sessions](references/learn-from-sessions.md).
