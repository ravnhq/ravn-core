# ravn-core 0.25 command migration

Version 0.25.0 removes old skill names. Use the replacement with your harness's command prefix, and update any project instructions or automation that names a retired skill.

| Retired skill | Replacement |
| --- | --- |
| `grill-me` | `grilling` |
| `create-verification-skill` | `verification-skill create` |
| `maintain-verification-skill` | `verification-skill maintain` |
| `create-formal-verification-skill` | `formal-verification-skill create` |
| `maintain-formal-verification-skill` | `formal-verification-skill maintain` |
| `principle-boundary-discipline` | `codebase-design`, for raw inputs and adapters |
| `principle-type-system-discipline` | `codebase-design` for generic contracts or `typescript-best-practices` for TypeScript |
| `principle-guard-the-context-window` | The fact-gathering phase of `ship`, or `why` for a long history search |

In existing generated formal verification guides, change the maintenance command to `formal-verification-skill maintain`. Keep the project's assumptions, bounds, and recorded sync commit; changing the command does not rerun the proof or update that commit.

`principle-build-the-lever` and the shared-write ownership principle remain standalone skills.
